## 專案簡介

這是一個基於 **日本麻將（Riichi Mahjong）** 的聽牌練習網頁遊戲。
玩家需在 3 分鐘內，從 34 張麻將牌中找出當前手牌的所有正確聽牌，考驗對麻將牌型的熟悉度與反應速度。

## 功能特色

- 🀄 **34 張麻將鍵盤** — 使用 Unicode 麻將圖示（🀇🀈🀉...）直觀選牌
- 📚 **豐富題庫** — 包含兩面聽、坎張、邊張、單騎、雙碰、諾貝坦、三面聽、煙囪聽、清一色多面聽、九蓮寶燈等 30 題
- ⏱ **3 分鐘限時挑戰** — 時間壓力下訓練聽牌判斷力
- 🏆 **排行榜系統** — 成績自動上傳，同玩家只取最高分
- 💾 **資料持久化** — 排行榜資料儲存於 `leaderboard.json`

## API 說明

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/leaderboard` | 取得排行榜前 10 名 |
| POST | `/api/score` | 上傳成績 `{ name, score }` |

## 遊戲規則

1. 輸入暱稱，點擊「開始挑戰」
2. 畫面顯示 13 張手牌，從下方 34 張牌中選出所有能和的牌
3. 多面聽須全選所有正確聽牌
4. 每題答錯會顯示正確答案，然後繼續下一題
5. 3 分鐘結束或按下「提早結算」即結算成績並上傳排行榜
