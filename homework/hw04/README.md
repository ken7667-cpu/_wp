# 10 JavaScript Programming Exercises

這個專案包含了 10 個由基礎到進階的 JavaScript 程式練習題，主要用於練習 JS 的核心語法與資料處理能力。專門為資工系 (CS) 學生設計的練習菜單！🚀

## 涵蓋核心觀念 (Core Concepts)
每個練習都至少包含了以下幾種語法組合：
- **條件判斷 (Conditional Statements)**: `if`, `else`
- **迴圈控制 (Loops)**: `for`, `while`
- **資料結構 (Data Structures)**: `Array` (陣列), `Object` (物件)
- **資料交換 (Data Interchange)**: `JSON`
- **模組化 (Modularity)**: `Function` (函式)

## 練習題目列表 (Exercise List)

1. **判斷奇偶數 (Check Even/Odd)**: 練習基礎的 `function` 與 `if` 判斷。
2. **陣列元素加總 (Array Sum)**: 結合 `function`, `array` 與 `for` 迴圈。
3. **使用 While 尋找目標 (Find Target with While)**: 練習使用 `while` 迴圈走訪陣列尋找特定值。
4. **解析 JSON 資料 (Parse JSON)**: 練習將 JSON 格式字串轉換為 JavaScript `object`。
5. **篩選及格學生 (Filter Passing Students)**: 結合 `array`, `object`, `for` 與 `if` 進行資料篩選。
6. **產生 JSON 格式報表 (Generate JSON Report)**: 練習建立 `object` 並使用 `JSON.stringify` 轉換格式。
7. **反轉陣列 (Reverse Array)**: 不依賴內建函式，使用 `while` 手動反轉 `array`。
8. **統計水果數量 (Count Fruits)**: 經典的面試題型，利用 `object` 的鍵值對特性統計陣列元素。
9. **計算購物車總價 (Calculate Cart Total)**: 實用的商業邏輯，結合 `json` 解析與 `while` 迴圈計算總和。
10. **綜合挑戰 - 找出最年長的使用者 (Comprehensive Challenge)**: 大魔王關卡！一次包含 `if`, `for`, `while`, `function`, `json`, `array`, `object` 所有要素的綜合資料處理。

請確保你的電腦有安裝 [Node.js](https://nodejs.org/)。

將程式碼儲存為 `.js` 檔案 (例如 `exercises.js`)，打開終端機 (Terminal) 並輸入：
```bash
node exercises.js
