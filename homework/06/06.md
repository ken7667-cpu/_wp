# JavaScript 函數與參數 — 習題 6 解答

## 01 - Callback 基礎實作 (`01-callback-basic.js`)

```js
function mathTool(num1, num2, action) {
  return action(num1, num2);
}

console.log(mathTool(10, 5, function (a, b) { return a + b; }));
console.log(mathTool(10, 5, function (a, b) { return a - b; }));
```

- `mathTool` 接受兩個數字與一個回呼函數。
- 分別傳入匿名函數進行相加與相減。

## 02 - 匿名函數與 IIFE (`02-iife.js`)

```js
(function () {
  const count = 100;
  console.log("Count is: " + count);
})();
```

- 使用 IIFE 建立獨立作用域，外部無法存取 `count`。

## 03 - 箭頭函數與陣列轉換 (`03-arrow-map.js`)

```js
const prices = [100, 200, 300, 400];
const discounted = prices.map(p => p * 0.8);
console.log(discounted);
```

- `map` 搭配單行箭頭函數將每項價格打 8 折。

## 04 - 陣列參數的「破壞性修改」(`04-destructive-modify.js`)

```js
function cleanData(arr) {
  arr.pop();
  arr.unshift("Start");
}

let myData = [1, 2, 3];
cleanData(myData);
console.log(myData);
```

- `pop()` 移除最後一項，`unshift("Start")` 在最前面插入。
- 因為陣列是傳參考，原陣列直接被修改。

## 05 - 函數回傳函數 (`05-higher-order.js`)

```js
function multiplier(factor) {
  return n => n * factor;
}

const double = multiplier(2);
console.log(double(10));
```

- `multiplier` 是高階函數，回傳一個閉包（箭頭函數）。

## 06 - Callback 篩選器 (`06-callback-filter.js`)

```js
function myFilter(arr, callback) {
  const result = [];
  for (let i = 0; i < arr.length; i++) {
    if (callback(arr[i])) {
      result.push(arr[i]);
    }
  }
  return result;
}

const filtered = myFilter([1, 5, 8, 12], function (item) { return item > 7; });
console.log(filtered);
```

- 手刻 `filter` 邏輯，利用回呼函數決定保留元素。

## 07 - 箭頭函數處理物件 (`07-arrow-filter-object.js`)

```js
const users = [{ name: "Alice", age: 25 }, { name: "Bob", age: 17 }];
const adults = users.filter(user => user.age >= 18);
console.log(adults);
```

- `filter` + 箭頭函數篩選年齡 ≥ 18 的使用者。

## 08 - 參數傳址陷阱 (`08-pass-by-reference.js`)

```js
let listA = [1, 2];
let listB = [3, 4];

function process(a, b) {
  a.push(99);
  b = [100];
}

process(listA, listB);

console.log("listA:", listA);   // [1, 2, 99]
console.log("listB:", listB);   // [3, 4]
```

- `a.push(99)` 修改了原陣列（傳址）。
- `b = [100]` 只是將區域變數 `b` 指向新陣列，不影響原 `listB`。

## 09 - 延遲執行的 Callback (`09-delayed-callback.js`)

```js
setTimeout(() => {
  const arr = ["Task", "Completed"];
  console.log(arr.join(" "));
}, 2000);
```

- `setTimeout` 2 秒後以箭頭函數執行 `join(" ")`。

## 10 - 綜合應用：計算總價 (`10-calculate-total.js`)

```js
function calculateTotal(cart, discountFunc) {
  const sum = cart.reduce((acc, price) => acc + price, 0);
  return discountFunc(sum);
}

const result = calculateTotal([100, 200, 300], function (total) { return total - 50; });
console.log(result);
```

- `reduce` 加總購物車金額，再傳入折扣回呼函數處理。
