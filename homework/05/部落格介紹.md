# OpenCode 網誌系統

一個使用 Node.js + Express 開發的完整網誌系統，支援使用者認證、文章管理、社群互動等功能。

---

## 特色

- **漸進式開發**：從基礎功能逐步擴充，共四個版本
- **輕量無框架**：純原生 HTML/CSS/JS，無前端框架依賴
- **卡片式 UI**：現代化的介面設計，支援深色/淺色主題
- **即時 Markdown**：文章使用 Markdown 語法撰寫，自動渲染
- **社群功能**：留言、按讚、追蹤，打造互動社群

---

## 版本列表

| 版本 | 說明 |
|------|------|
| **Blog 1** | 基礎網誌 — 註冊登入、文章 CRUD、公開/私人權限 |
| **Blog 2** | 主題美化 — 深色模式切換、CSS 動畫、響應式設計 |
| **Blog 3** | 社群互動 — 留言回覆、按讚功能、追蹤系統 |
| **Blog 4** | 升級優化 — 編輯文章、帳號設定、搜尋功能 |

---

## 快速開始

```bash
# 進入任一版本目錄
cd "blog 1"   # 或 blog 2, blog 3, blog 4

# 安裝依賴
npm install

# 啟動伺服器
npm start
```

開啟瀏覽器訪問 `http://localhost:3000` 開始使用。

> Blog 4 會自動讀取 Blog 3 的資料庫，升級時原有資料不遺失。

---

## 使用流程

1. **註冊帳號** — 填寫使用者名稱與密碼
2. **登入系統** — 使用帳密進行登入
3. **寫新文章** — 支援 Markdown 語法
4. **設定權限** — 選擇是否發布到公共區域
5. **瀏覽互動** — 留言、按讚、追蹤其他作者
6. **個人設定** — 編輯自我介紹、變更密碼

---

## 技術棧

- **執行環境：** Node.js
- **後端框架：** Express.js
- **資料庫：** SQLite（sql.js）
- **認證：** bcryptjs + express-session
- **Markdown：** marked
- **模板：** HTML 內嵌（JavaScript 模板字串）
- **樣式：** CSS 自定義屬性（深色/淺色主題）
