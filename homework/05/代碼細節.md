# 代碼細節與功能說明

## 整體架構

- **後端框架：** Express.js
- **資料庫：** SQLite（透過 sql.js 套件操作）
- **模板引擎：** HTML 內嵌（使用 JavaScript 模板字串）
- **認證機制：** bcryptjs（密碼雜湊）+ express-session（Session 管理）
- **Markdown 渲染：** marked

## 版本演進

### Blog 1 — 基礎版

- 使用者註冊/登入/登出
- 文章發布（支援 Markdown 語法）
- 公開/私人貼文權限控制
- Session 管理狀態
- 卡片式設計、漸變背景

### Blog 2 — 深色主題版

- 延續 Blog 1 所有功能
- CSS 變數實現深色/淺色主題切換
- localStorage 儲存主題偏好
- 動畫效果（fadeIn、hover）
- 響應式設計（RWD）

### Blog 3 — 社群互動版

- 延續 Blog 2 所有功能
- **留言系統：** 文章底下留言，支援巢狀回覆
- **按讚功能：** 文章與留言均可按讚/取消讚
- **追蹤系統：** 追蹤/取消追蹤其他使用者
- **個人檔案頁：** 顯示使用者文章列表與追蹤統計
- **首頁分頁：** 「全部」與「追蹤中」切換

### Blog 4 — 升級優化版

- 延續 Blog 3 所有功能
- **編輯文章：** 作者可修改標題、內容、公開狀態
- **帳號設定：** 自我介紹編輯、密碼變更
- **文章搜尋：** 依標題關鍵字搜尋
- **資料庫共用：** 直接讀寫 blog 3 的資料庫，保留原有資料

## 資料庫結構

### users 表

| 欄位 | 類型 | 說明 |
|------|------|------|
| id | INTEGER PK | 使用者 ID |
| username | TEXT UNIQUE | 使用者名稱 |
| password | TEXT | bcrypt 加密密碼 |
| bio | TEXT | 自我介紹（blog 4 新增） |
| created_at | DATETIME | 建立時間 |

### posts 表

| 欄位 | 類型 | 說明 |
|------|------|------|
| id | INTEGER PK | 文章 ID |
| title | TEXT | 文章標題 |
| content | TEXT | 文章內容（Markdown） |
| author_id | INTEGER FK | 作者 ID |
| is_public | INTEGER | 是否公開（0/1） |
| created_at | DATETIME | 建立時間 |

### comments 表

| 欄位 | 類型 | 說明 |
|------|------|------|
| id | INTEGER PK | 留言 ID |
| post_id | INTEGER FK | 所屬文章 ID |
| author_id | INTEGER FK | 留言者 ID |
| parent_id | INTEGER FK | 父留言 ID（巢狀回覆用） |
| content | TEXT | 留言內容 |
| created_at | DATETIME | 建立時間 |

### likes 表

| 欄位 | 類型 | 說明 |
|------|------|------|
| id | INTEGER PK | 按讚 ID |
| user_id | INTEGER FK | 按讚者 ID |
| target_type | TEXT | 目標類型（post/comment） |
| target_id | INTEGER | 目標 ID |
| created_at | DATETIME | 建立時間 |

### follows 表

| 欄位 | 類型 | 說明 |
|------|------|------|
| id | INTEGER PK | 追蹤 ID |
| follower_id | INTEGER FK | 追蹤者 ID |
| followed_id | INTEGER FK | 被追蹤者 ID |
| created_at | DATETIME | 建立時間 |

## 路由設計

| 路由 | 方法 | 權限 | 說明 |
|------|------|------|------|
| `/` | GET | 公開 | 首頁（文章列表/搜尋/分頁） |
| `/register` | GET/POST | 公開 | 註冊 |
| `/login` | GET/POST | 公開 | 登入 |
| `/logout` | GET | 需登入 | 登出 |
| `/posts/new` | GET | 需登入 | 寫新文章 |
| `/posts` | POST | 需登入 | 發布文章 |
| `/posts/:id` | GET | 公開/作者 | 檢視文章 |
| `/posts/:id/edit` | GET/POST | 作者 | 編輯文章 |
| `/posts/:id/delete` | POST | 作者 | 刪除文章 |
| `/posts/:id/like` | POST | 需登入 | 按讚/取消讚 |
| `/posts/:id/comments` | POST | 需登入 | 留言 |
| `/comments/:id/reply` | POST | 需登入 | 回覆留言 |
| `/comments/:id/like` | POST | 需登入 | 留言按讚 |
| `/comments/:id/delete` | POST | 作者 | 刪除留言 |
| `/users/:id` | GET | 公開 | 個人檔案 |
| `/users/:id/follow` | POST | 需登入 | 追蹤/取消 |
| `/settings` | GET/POST | 需登入 | 帳號設定 |

## 安全性措施

- 密碼使用 bcrypt 進行雜湊儲存
- Session 管理使用者狀態
- 權限驗證中介軟體（requireAuth）
- 文章/留言僅作者可刪除
- 私人文章僅作者可查看
- XSS 防護透過 HTML 跳脫（esc 函數）
- 資料庫操作使用參數化查詢防 SQL 注入
