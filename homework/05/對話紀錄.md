# 對話紀錄

## 第一輪：建立專案

**使用者要求：** 根據 README.md 描述建立網誌系統。

**助理回應：** 建立 blog 1（基礎版）和 blog 2（深色主題版）兩個版本，包含 Express 伺服器、SQLite 資料庫、使用者認證、文章 CRUD、公開/私人權限、Markdown 渲染、主題切換等功能。

## 第二輪：使用者詢問如何使用

**使用者提問：** 要有 server 要怎麼使用？

**助理回應：** 說明 `cd "blog 1"` 或 `cd "blog 2"` 後執行 `npm start`，開啟瀏覽器訪問 `http://localhost:3000`，並說明操作流程。

## 第三輪：使用者詢問 npm start 執行位置

**使用者提問：** 我要去哪裡執行 npm start？

**助理回應：** 提供完整的 PowerShell 指令路徑與執行方式。

## 第四輪：使用者要求新增社群功能

**使用者要求：** 新增留言（含巢狀回覆）、按讚（文章與留言）、追蹤功能，並建立 blog 3 新版本。

**助理回應：** 建立 blog 3 版本，在 blog 2 的基礎上新增：
- 文章留言系統
- 巢狀回覆（留言可回覆留言）
- 文章按讚功能
- 留言按讚功能
- 使用者追蹤系統
- 個人檔案頁面
- 首頁「追蹤中」分頁

## 第五輪：使用者要求保留資料

**使用者要求：** 版本更新後應該保留原本的帳號和貼文，製作 blog 4。

**助理回應：** 建立 blog 4 版本，資料庫指向 blog 3 的 blog.db，無痛升級。新增功能：
- 編輯文章（標題、內容、公開狀態）
- 帳號設定（自我介紹、變更密碼）
- 文章搜尋（依標題關鍵字）

## 第六輪：使用者回報錯誤

**使用者回報：** EADDRINUSE port 3000 已被佔用。

**助理回應：** 執行指令終止佔用 port 3000 的程序，確認 port 釋放後成功啟動伺服器。

## 第七輪：使用者要求撰寫文件與上傳

**使用者要求：** 撰寫三份 .md 檔案（對話紀錄、代碼細節、部落格介紹），並將整個 05 資料夾推送到 GitHub。
